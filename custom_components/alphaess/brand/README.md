# AlphaESS brand images

These PNGs are unchanged copies of the AlphaESS assets in the official
[Home Assistant brands repository](https://github.com/home-assistant/brands/tree/0e8bc1c1fbe87d711d4864d657d5a5ed8125ada2/custom_integrations/alphaess),
at commit `0e8bc1c1fbe87d711d4864d657d5a5ed8125ada2`.

The source contains no separate dark-theme variants. Home Assistant uses these
default images for both themes. AlphaESS retains ownership of its branding.

Home Assistant serves these bundled files through its local brands API; no
configuration is required. See the
[custom integration branding announcement](https://contributors.home-assistant.io/blog/2026/02/24/brands-proxy-api/).
